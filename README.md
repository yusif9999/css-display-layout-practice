# Tech Conference Landing Page

A realistic, single-page technology conference website built strictly with HTML5 and Vanilla CSS. This project serves as a practical application of core CSS concepts, specifically focusing on mastering traditional layout techniques before moving on to modern layout systems.

## 🎯 Project Focus & Learning Outcomes

The primary goal of this repository is to demonstrate a solid understanding of the CSS Box Model, text formatting, and particularly the `display` property, without relying on Flexbox or CSS Grid. 

Key technical achievements in this project include:
* **Display Property Mastery:** 
  * Utilizing `display: inline-block` effectively to align pricing cards horizontally.
  * Using `display: block` to convert inline links into full-width clickable buttons.
  * Applying `display: none` to completely remove sold-out elements from the document flow.
* **Visibility Control:** Implementing `visibility: hidden` to hide text while maintaining its spatial footprint, preventing layout shifts in the ticket cards.
* **Advanced Selectors:** Efficiently styling elements using pseudo-classes like `:nth-child()`, `:first-child`, and `:last-child` to keep the HTML clean and avoid redundant class names.
* **Table Styling:** Constructing a well-spaced, highly readable schedule table utilizing `border-collapse`, padding, and alternating row colors.
* **Typography & Assets:** Integrating external resources such as Google Fonts (Source Sans 3) and FontAwesome icons for a modern UI feel.

## 🛠️ Technologies Used

* **HTML5:** Semantic document structure
* **CSS3 (Vanilla):** Styling, layout, and visual hierarchy
* **Google Fonts:** Custom typography integration
* **FontAwesome:** Scalable vector icons
